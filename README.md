# NeuroHub

**EN** — NeuroHub is a desktop hub for AI chats, email, office and handy utilities,
with a built‑in browser and secure DNS routing.

**RU** — NeuroHub — настольный хаб для нейросетей, почты, офиса и удобных утилит,
со встроенным браузером и безопасным DNS.

## Download / Скачать

Get the latest installer from the **[Releases](../../releases/latest)** page →
`NeuroHub-Setup-x.y.z.exe`

Скачайте установщик на странице **[Releases](../../releases/latest)** →
`NeuroHub-Setup-x.y.z.exe`

## Updates / Обновления

The app checks for updates automatically and shows a notification when a newer
version is available. Just click **Download** in the banner.

Приложение само проверяет обновления и показывает уведомление, когда выходит
новая версия. Достаточно нажать **Скачать** в баннере.
